# Languages (German / English)

- Interface texts live in [`scripts/i18n.mjs`](../scripts/i18n.mjs) (`UI_TEXT.de` / `UI_TEXT.en`) and in the older
  `strings` table of `scripts/app.source.mjs`. Code uses `tr('key', {placeholder: value})` or `t('key')`; it never
  chooses a language inline.
- Static HTML texts carry `data-i`, `data-i-aria`, `data-i-title` or `data-i-placeholder`; `language()` fills them.
- MapLibre's own labels (zoom buttons, popup close, map title) come from `mapLibreLocale()`.
- Display names of OpenStreetMap values in popups: `OSM_VALUES`; English falls back to readable words
  (`paving_stones` → "Paving stones").
- Bilingual data tables keep both languages side by side: themes, POI types, crossing classes, profiles.
  The guide (`scripts/guide.mjs`) and the About text are bilingual documents.
- `scripts/check_i18n.mjs` (part of `npm test`) fails when a key misses a language, placeholders differ, a module
  chooses a language inline, an HTML key is unknown or a German attribute in `index.html` has no key.

New features add their texts to `UI_TEXT` in both languages.
