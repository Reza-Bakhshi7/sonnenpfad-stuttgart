# Eight-week roadmap

1. Governance, repository and Cloudflare baseline.
2. Versioned data catalogue and reproducible export pipeline.
3. Full Stuttgart coverage, tiled data and terrain.
4. Basemaps, thematic layers and optimized 3D presentation.
5. Routing profiles, restrictions and accessibility preferences.
6. Live weather, sun direction and cloud-aware shade weighting.
7. Estimated ÖPNV/SPNV vehicle positions with freshness and confidence.
8. Browser, accessibility, load, failure-mode and release testing.

Each increment is delivered through a focused branch and pull request. Public releases require verified data sources, attribution, documentation and a rollback point.
